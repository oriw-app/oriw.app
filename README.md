# oriw.app

Website for [Oriw](https://oriw.app), the open-source, local-first whiteboard. Served on GitHub Pages at oriw.app.

## Edit the site

The whole site is one file, `index.html`. Links to GitHub, releases and the waitlist are set in one place: the `LINKS` list near the bottom of the file.

## Deploy

GitHub Pages serves the `main` branch root. `CNAME` points the site at `oriw.app`; `.nojekyll` serves files as-is.
